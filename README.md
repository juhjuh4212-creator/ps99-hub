# PS99 자동 (Pet Simulator 99)

랭크 퀘스트를 밀면서 존을 해금하는 자동화 스크립트.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/juhjuh4212-creator/ps99-hub/main/PS99_Loader.lua"))()
```

`HttpGet` 이 막힌 익스큐터면 [`PS99_GardenAuto.lua`](PS99_GardenAuto.lua) 전체를 복사해 붙여넣으세요. 내용은 같습니다.

> 개인적으로 만든 것입니다. 쓰다가 계정에 무슨 일이 생겨도 책임 못 집니다.

## 뭘 하나

**올 자동** 을 켜면 이 순서로 돕니다.

매 바퀴 먼저 (이동이 필요 없는 것)
- 알 해금 / 슬롯 머신(부화 개수·펫 최대치) / 맵 업그레이드 / 버프 유지

그다음 우선순위대로
1. 리버스
2. 존 해금
3. 랭크 퀘스트 + 보상 수령

퀘스트는 하나를 잡으면 **목표에 도달할 때까지** 붙잡고, 그 사이에는 리버스·존 해금을 끼워넣지 않습니다. 퀘스트가 끝난 뒤에 다시 1번부터 봅니다.

돈이 떨어지면 최고 존에서 벌어오고, 남은 개수를 채울 만큼 모이면 돌아갑니다.

여러 단계를 거쳐야 하는 퀘스트(골드/레인보우 펫, 포션·인챈트 업그레이드)는 무시합니다.

## UI

| 탭 | 내용 |
|---|---|
| 대시보드 | 현재 하는 행동, 통계 |
| 이벤트 | 가든 디펜더스 |
| 메인 게임 | 파밍·존해금·부화·랭크·퀘스트·아이템·슬롯·맵업글·올자동 |
| 로그 | 전부. 우측 상단 **복사** 로 클립보드에 |

우측 상단에 **정지** 와 **종료**. 정지는 이동 중이어도 즉시 멈춥니다.
